# apuntes-ciberseguridad

# 🛡️ Bitácora de Formación: Ciberseguridad y Sistemas

Registro práctico de conceptos, diagnósticos y glosario técnico construido paso a paso.

## 🌐 Módulo 1: Fundamentos de Redes (Completado)
* **Diagnóstico de conectividad:** Uso de `ping` para diferenciar fallas de salida a internet (IP directa) vs. fallas de resolución de nombres (DNS).
* **Identificación de dispositivos:** Diferencia operativa entre **Dirección IP** (asignada por la red local/router, dinámica) y **Dirección MAC** (identificador físico de fábrica de la tarjeta de red).
* **Puertos y Servicios:** Comprensión de puertos lógicos como puntos de entrada/salida (ej. `80/443` Web, `22` SSH).

### 📖 Glosario Técnico (Inglés -> Español)
* **Host:** Cualquier dispositivo conectado a una red con una dirección IP asignada.
* **Packet (Paquete):** Unidad mínima de datos en la que se divide la información para viajar por internet.
* **Timeout (Tiempo agotado):** Error que ocurre cuando un equipo envía una petición y el destino no responde dentro del tiempo esperado.
